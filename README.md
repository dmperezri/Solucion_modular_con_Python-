# Sistema de facturación

Programa desarrollado en Python utilizando programación estructurada y modular.

## Funcionalidades

- Registro del nombre del cliente.
- Ingreso de varios productos.
- Cálculo de subtotales.
- Cálculo de descuento.
- Cálculo de IVA.
- Descuento adicional por volumen.
- Validación de datos ingresados.
- Generación de factura en consola.

## Archivos

- `principal.py`: contiene la lógica principal del sistema.
- `utilerias.py`: contiene funciones auxiliares para limpiar la pantalla y validar números.

## Ejecución

Ejecutar:

```bash
python principal.py
